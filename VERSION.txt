Ежедневник — версия 0.6 FINAL

База: personal-planner-v0-6-final(1).

Точечные правки по последним замечаниям:
1. Фокус недели
- Задачи стали компактнее: одновременно видно больше строк.
- Список задач прокручивается только при переполнении.
- Новая задача добавляется отдельной строкой и не вклинивается в существующую.
- Добавлены мягкие пастельные цветовые акценты.
- Цвет задачи можно менять нажатием на цветную точку.
- Выполнение, редактирование и удаление сохранены.

2. Фокус месяца
- Полностью приведён к последнему референсу: большой Фокус месяца, Сферы жизни 2×2, Заметки.
- Цели/Планы убраны из отдельного ряда.
- В каждой сфере есть отдельная цель и список задач.
- Задачи можно добавлять, выполнять, редактировать и удалять.
- Карточки сфер фиксированного размера.
- При переполнении прокручивается только список внутри конкретной сферы.
- Старые данные сфер мигрируются без потери пунктов.

Остальные рабочие механики версии не переписывались.
