Ежедневник — версия 0.6

База: версия 0.5.

Внесено только по актуальному ТЗ и правкам:

1. Неделя
- Геометрия разворота: ПН/ВТ/СР слева, ЧТ/ПТ справа, СБ и ВС — отдельные горизонтальные карточки друг под другом в нижней правой области.
- Карточки фиксированы и не растягиваются.
- Внутри карточки прокручивается только список задач.
- Выполнение и главная задача сохранены.

2. Фокус недели
- Три строки фокуса имеют компактную фиксированную высоту.
- Блок «Задачи» рассчитан минимум на три задачи без внутренней прокрутки.
- При большем количестве прокручивается только список задач.
- «Итог» без внутренней прокрутки: три поля всегда видны и имеют фиксированную высоту.
- Блок «Итог» увеличен относительно фокуса недели.

3. Месяц
- Полная сетка 7×6.
- Весь месяц помещается в рабочей области телефона без прокрутки самой сетки.
- Цветные задачи-кирпичики.
- +N при переполнении.
- Сегодня и кнопка «Сегодня».
- Единое окно дня.

4. Фокус месяца
- Отдельная страница по референсу.
- Фокус месяца, Цели, Планы, Сферы жизни, Заметки.
- Цели/Планы/каждая сфера — функциональные списки с добавлением, выполнением, редактированием и удалением.
- Блоки фиксированного размера.
- При переполнении прокручивается только список внутри конкретного блока.
- Сферы: Финансы, Блог, Личное, Здоровье.

5. Навигация
- Горизонтальный свайп переключает недели.
- Горизонтальный свайп переключает месяцы.
- Свайп работает и в Развороте/Календаре, и внутри соответствующего Фокуса.
- Переключение Разворот/Фокус сохраняет текущий период.

6. Задачи
- Одна задача = один объект.
- Планер/Календарь — независимые флаги отображения.
- Дата, цвет, отображение и выполнение сохраняются.
- Выполнение визуально меняется только в неделе.
- Перенос меняет дату одной и той же задачи.

7. Редактирование задачи
- Дата сделана компактной и полностью читаемой.
- Сохранены Планер/Календарь, цвет и главная задача.

Данные из предыдущих локальных версий мигрируются в v0.6.
